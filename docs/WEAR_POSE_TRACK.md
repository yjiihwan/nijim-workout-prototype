# 아이템 입은 채 움직이기 — A안 ↔ B안 갈림 자리와 «위치 자료» 형식 (v2.12, 2026-11-28)

## 한 줄 요약
포즈(동작)를 틀 때마다 `charanim.js`의 `poseMode(캐릭터, 레벨, 포즈 이름)` 한 곳에서 갈라진다.

| 결과 | 조건 | 화면 |
|---|---|---|
| `clip` | 아이템 0개 | 미리 그려 둔 원래 포즈 영상 그대로 |
| `track` (B안) | 아이템 있음 + 그 포즈의 위치 자료 있음 + 재생기 등록됨 | 원래 포즈를 틀고 아이템을 장면마다 따라붙인다 |
| `aplan` (A안) | 아이템 있음 + 위치 자료 없음 | 공통 움직임: 숨쉬기 2% · 움츠림→폴짝 7%→착지(1.1초) · 깜빡임(졸림 표정 0.12초) · 5.2초 반복 · 탭하면 바로 폴짝 |

지금은 위치 자료가 0개라 아이템을 입으면 전부 A안이다.

## A안은 왜 손댈 게 없나
A안은 캐릭터 그림 칸(`.cimg`) 하나를 통째로 움직인다. 몸·팔·표정·아이템(앞·뒤, 배경·아우라·망토 포함)이 모두 그 칸 안에 있어서, 아이템이나 캐릭터·단계가 늘어도 같이 움직인다. 새 아이템을 `equip.js`에 그리기만 하면 되고 움직임 코드는 그대로다.
- 움직임 값: `style.css`의 `aBreath`·`aHop`(디자인 예시 `motion_a.css` 그대로)
- 언제 뛰는지: `charanim.js`의 `APLAN`(`aplanStart`·`aplanTap`·`aplanStop`)
- 어느 무대든 `.cwrap`에 `aplanStart(무대)`만 부르면 붙는다(첫 화면 무대·먹는 무대가 이렇게 쓴다).

## 포즈 이름
- `sig` 첫 화면 시그니처 포즈
- `eat` 먹고 마시는 장면
- 새 동작은 이름을 새로 지어 `poseMode(t, lv, '새이름')`으로 물어보면 된다. 위치 자료가 없으면 자동으로 A안이다.

## B안으로 넘어가는 순서
1. 위치 자료를 `assets/anim/wear_track.js`의 `WEAR_TRACK`에 넣는다(아래 형식). 포즈·캐릭터·단계 한 칸씩 넣어도 된다. 넣은 칸만 B안, 나머지는 계속 A안이다.
2. 재생기를 한 번 만든다: `WEAR_TRACK_PLAYERS.sig = (무대, 위치자료, {t, lv}) => { … return true; }`. 원래 포즈 영상을 틀고(`sigPlayHome`과 같은 방식), 장면이 바뀔 때마다 아이템 그림 층의 위치·각도를 위치 자료대로 옮긴다. `false`를 돌려주면 A안으로 떨어진다.
3. 재생기가 등록되기 전에는 위치 자료가 있어도 A안이 나온다(반쪽 상태로 화면이 깨지지 않게).

## 위치 자료 형식
```js
WEAR_TRACK[캐릭터][컷][포즈 이름] = {
  v: 1,
  n: 21,                      // 장면 수(포즈 영상과 같은 수·같은 순서)
  ms: [40, 40, …, 1520, …],   // 장면별 시간(ms). 포즈 영상과 같아야 한다
  f: [                        // 장면마다 1개
    {
      head:   [x, y, 각도, 배율],       // 머리 기준점(얼굴 가운데) — 모자·머리띠·왕관·안경·고글
      neck:   [x, y, 각도],             // 목 가운데 — 타월·메달·부적·헤드폰
      wristL: [x, y, 각도, 가림],       // 왼 손목 — 밴드·시계·스트랩·덤벨
      wristR: [x, y, 각도, 가림],
      waist:  [x, y, 각도, 폭],         // 허리 가운데 — 벨트·짐백·매트
      footL:  [x, y, 각도],             // 왼발 바닥 가운데 — 신발·무릎 보호대
      footR:  [x, y, 각도],
      body:   [dx, dy, 가로배율, 세로배율]  // 몸 전체가 서 있는 자세에서 얼마나 움직였나 — 뒤에 깔리는 배경·아우라·망토
    },
    …
  ]
};
```
- 좌표 단위: 그 컷 그림의 px, 왼쪽 위가 (0, 0). `equip.js`의 손목·몸 자리 표와 같은 단위다.
- 각도: 도(°), 시계 방향이 +. 서 있는 자세가 0.
- 가림(앞·뒤): `1` = 몸 앞에 보임, `-1` = 몸 뒤로 넘어감(몸 그림 밑에 그림), `0` = 이 장면에서는 안 보임. 손목 말고 다른 자리에도 맨 끝에 붙일 수 있다(없으면 1).
- 어느 자리가 빠져 있으면 그 자리 아이템은 서 있는 자세 위치 그대로 둔다.
- 컷 이름: `01`·`10`·…·`90`·`99` (`app.js` `cutOf`).
